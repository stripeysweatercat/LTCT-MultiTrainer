this is a tool that will generate a scramble with a specified ltct case / set of ltct cases. i created it to help with connecting a letter pair to each ltct, so that i can use ltct in multibld. i imagine it would also be useful for people who do not want to use it in multi.

## why are all my corners 3 algs?????????
because the corner state is generated by:
1. set the corners that are part of the ltct to their positions and orientations
2. figure out which corners 5 are not part of the ltct, and do 2 3 cycles from UFR using 4 of those
3. ignore the 5th corner that is not touched

this is to stop cycle break subjectivity from giving u a different ltct that you did not want to practice. im not actually sure if it works like that but it sounds right and this method was easy :P
